## The brief
Take the start code for the Shopping Cart project (teacher's `shopStart` files), then:
1. Add **REMOVE** buttons that do the opposite of the Add button
2. When removing, don't let quantities go negative
3. Add a **Checkout** button that totals the price of the items in the cart and puts the total on the page (make a **new function** for this)

## Files
- `index.html`: the page with the Checkout button and the `total` area
- `shopStart.js`: the teacher's starter, plus the new `remove_selection()` and `checkout()` functions
- `shopStart.css`: table styles from the starter, plus button styles

The original starter files are in `materials/shopping-cart-starter/`.
