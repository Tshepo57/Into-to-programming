## The brief
Starting code:
```js
var secret = 7;
var answer = prompt("Please guess the secret number (1-20)");
var guess = parseInt(answer);
```
1. Add an `if` statement: "Correct Guess!" or "Sorry, incorrect Guess!"
2. Combine lines 2 and 3 into one line
3. Put it in a `while` loop that only exits when the guess is correct
4. While wrong, say "Incorrect, too low" or "Incorrect, too high"
5. Make the secret number random
